# Harness / Verifikation

Konventionen werden mechanisch durchgesetzt, nicht nur dokumentiert.

- **Git-Hooks** (`make hooks`, in `make init`): `pre-commit` = gofmt auf gestagete Go-Dateien; `pre-push` = volles Gate (`go vet`, `go test ./...` inkl. Architektur-Test, `golangci-lint`, `pnpm -C web build/test/lint`, `openspec validate`). Race-Detector läuft separat via `make test-race` (~10× langsamer). Notausgang: `git push --no-verify`.
- **Architektur-Test** `internal/arch/arch_test.go` (stdlib, Teil von `make test`): Domain-Packages importieren sich nicht gegenseitig; Foundation importiert keine Domain/Composition; jedes neue `internal/`-Package muss klassifiziert werden.
- **Broadcast-Gate** `internal/arch/broadcast_test.go` (stdlib, Teil von `make test`): erzwingt die SSE-Hard-Rule „jede Mutations-Route broadcastet". Parst `BuildRouter`, prüft für jede `POST`/`PUT`/`PATCH`/`DELETE`-Route, dass der Handler-Rumpf einen Broadcast-artigen Aufruf enthält (`h.hub.Broadcast`/`BroadcastToUsers` **oder** einen Helfer wie `broadcastMembers`). Bewusste Ausnahmen (kein Hub-Live-Update, eigener Kanal wie Chat, pro-Nutzer/Session, Mailversand) stehen mit Begründung in der `broadcastAllowlist`; ein verwaister Allowlist-Eintrag (Route existiert nicht mehr) lässt den Test ebenfalls fehlschlagen.
- **SEPA-XSD-Gate** `web/src/lib/sepaXml.xsd.test.ts` (Teil von `pnpm -C web test`): validiert jede `buildPainXML()`-Ausgabe mechanisch gegen das eingecheckte DK-TVS-XSD (Version + Herkunft: `web/src/lib/__schemas__/README.md`). Shell-outet `xmllint` (libxml2). Deckt Standard-Fall, fehlendes Mandatsdatum, fehlende Stadt, Multi-Transaktion, AT-IBAN + Straße-ohne-Hausnummer sowie zwei Poison-Meta-Sanity-Tests ab (manipuliertes XML **muss** rejecten — beweist, dass der Validator scharf ist). Ohne `xmllint` (macOS-Standard, Linux via `apt-get install libxml2-utils`) skippt der Test lokal mit sichtbarem `console.warn`. In CI setzt `.github/workflows/ci.yml` `TEAMWERK_REQUIRE_XSD=1` — fehlt xmllint dort, failt der Test hart statt still zu skippen.
- **Push-Fan-out-Gate** `internal/arch/pushfanout_test.go` (stdlib, Teil von `make test`, analog zum Broadcast-Gate): erzwingt, dass `push.SendToUsers` außerhalb von `internal/notify`/`internal/push` nicht mehr direkt aufgerufen wird — jeder Domänen-Code, der Push von Hand nachbaut, umgeht sonst stillschweigend den Event-Log (`user_events`), weil `eventlog.Record` nur in `notify.Send` sitzt. Ausnahmen (aktuell nur `push.SendToUserWithBadge` in `internal/chat`, eigener Kanal, bewusst nicht im Log) stehen mit Begründung in einer Allowlist analog `broadcastAllowlist`; ein verwaister Eintrag lässt den Test ebenfalls fehlschlagen.
- **Goroutine-Gate** `internal/arch/goroutine_test.go` (stdlib, Teil von `make test`): jeder `go`-Start unter `internal/` (außer `background`, `hub`) muss über `background.Go(name, fn)` oder `notify.SendAsync` laufen — beide fangen Panics per `recover()`, loggen sie mit Job-Namen und zählen `teamwerk_background_panics_total`. Ein nackter `go func()` im Domänencode reißt sonst bei einem Panic den ganzen Prozess mit. Ausnahmen mit Begründung in `goroutineAllowlist` (aktuell leer); verwaiste Einträge lassen den Test fehlschlagen.
- **Objektrechte-Matrix** `internal/permissions/object_matrix_test.go` (Teil von `make test`): Ergänzung zur Tier-Matrix (`matrix_test.go`, die auf leerer DB mit Pfad-ID `1` nur Auth-Tiers beweist). Legt je `{id}`-Route ein Objekt an, das Nutzer B gehört, ruft es als Nutzer A und verlangt 403/404. Neue `{id}`-Route ohne Fixture-Erzeuger = rot; `openByDesign` (vereinsweit sichtbar, mit Begründung), `knownGaps` (offene Befunde, werden rot, wenn der Befund verschwindet) und `todoFixtures` (noch nicht modelliert) sind die drei sichtbaren Listen; verwaiste Einträge lassen den Test fehlschlagen.
- **gofmt-Selbstkorrektur:** `PostToolUse`-Hook (`scripts/claude-gofmt-hook.sh`) formatiert via Edit/Write geänderte `*.go`-Dateien.
- **Pre-Completion:** Slash-Command **`/verify-change`** prüft Build/Test/Lint + Projekt-Invarianten (Route→Tests, Mutation→`Broadcast`/`useLiveUpdates`, brand-Tokens, lucide-Icons, Migrationsnummer, `openspec validate`).
- **Permissions:** geteilte Routine-Befehle in `.claude/settings.json`; `.claude/settings.local.json` (gitignored) nur maschinenspezifisch.

## Eskalation (wenn etwas klemmt)

Nicht raten, nicht in einer Schleife festfahren — sauber an den Menschen übergeben, sobald:

- **Gate bleibt rot:** Nach **3** erfolglosen Versuchen, denselben Test/Lint/Build-Fehler zu beheben → stoppen, Stand + Fehlausgabe + Hypothese zusammenfassen, fragen. Kein `--no-verify`, keine Symptom-Workarounds, keine abgeschwächten Assertions zur Grün-Färbung.
- **Irreversibel/riskant:** Prod-Migration, `make deploy`, Daten löschen/überschreiben, Secrets — vor der Ausführung bestätigen lassen.
- **Mehrdeutig:** Anforderung lässt mehrere sinnvolle Interpretationen zu → kurz nachfragen statt eine Variante zu unterstellen.
